Backend URL must be the Railway API (https://job-scanner-bider-production.up.railway.app), not the Netlify dashboard and not 127.0.0.1 unless you are running FastAPI locally.

Your name labels this Chrome profile’s Bider rows on the dashboard (kenji queued, kenji ready, kenji skipped) and resets each Japan calendar day. It is stored only in this profile. The extension no longer reads your platform user name. Job Bider will not start until a name is set.

Search Chrome profile: Job Scan ON, Job Bider OFF. Stay logged in on CrowdWorks / Lancers / Coconala. The extension fetches listing URLs with this profile’s cookies and POSTs jobs to Railway. Railway never stores platform passwords.

Apply Chrome profile: Job Scan OFF, Job Bider ON. Opens queued jobs from the shared Railway queue. Does not scan. Never auto-submits.

Alarm interval: Dashboard source intervals are honored as much as Manifest V3 allows. Chrome alarms usually fire at most every 30 seconds (unpacked) or 1 minute (packed). A 60s dashboard interval therefore becomes ~1 minute. Per-source last-run in extension storage still skips a source until its interval has elapsed.
